# BlackJack Predictor
* Monte Carlo algorithm based blackjack win chance predictor with stylish frontend
* Algorithm written in Python
* Languages used: Python, HTML, CSS, Javascript
* Tools used: Flask, TailwindCSS, DaisyUI

### Configure Environment
* (Ensure npm and pip are installed)
* Run ```pip install -r requirements.txt``` in terminal
* Run ```npm install``` in terminal

### Run Program
* Run app.py
